# 딸깍 방과후강사 신고자료

**Repository:** `ddalkkak-instructor-reporting`  
**English name:** Ddalkkak Instructor Reporting

방과후강사 관련 월별 신고자료를 한 번에 생성하는 브라우저 기반 업무자동화 도구입니다.

## 주요 기능

- 소득자료 Excel 불러오기
- 강사명단 대조
- 원천세 전자신고자료 생성
- 간이지급명세서 생성
- 노무제공자 월보수액 신고자료 생성
- 3종 신고자료 ZIP 일괄 다운로드

## 개인정보 보호 설계

이 도구는 정적 웹앱으로 동작하며, 사용자가 선택한 소득자료와 강사명단은 서버로 업로드하지 않습니다.
파일 처리는 사용자의 브라우저 메모리에서만 이루어집니다.

- 주민등록번호 서버 전송 없음
- localStorage / 쿠키에 주민등록번호 저장하지 않음
- 화면에서는 주민등록번호 전체를 표시하지 않음
- 강사명단을 암호화된 `.ddkstaff` 파일로 저장 가능

> 실제 신고 전에는 생성된 파일의 내용을 반드시 확인하세요.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.
GitHub Pages로 배포하면 별도 설치 없이 웹주소로 실행할 수 있습니다.
