# 딸깍 방과후강사 신고자료

**Ddalkkak Instructor Reporting**  
방과후강사 관련 월별 신고자료를 한 번에 생성하는 브라우저 기반 업무자동화 도구입니다.

## 버전

- **Excel v1.0** — 기존 Excel/VBA 배포판
- **Web v2.0** — 현재 정식 웹 배포판
- 제작자: **나대현 · 천안버들유치원**

## 주요 기능

- 기관 기본정보 파일 불러오기 / 저장
- 광역단체 → 관할 세무서 선택 및 세무서 코드 자동 입력
- 암호화된 소득자료 Excel 불러오기
- 암호화된 강사명단 Excel 또는 딸깍 암호화 명단(`.ddkstaff`) 불러오기
- 이름 + 주민번호 앞 6자리 자동 대조
- 원천세 전자신고자료 생성
- 간이지급명세서 TXT 또는 XLSX 생성
- 노무제공자 월보수액 신고 XLSX 생성
- 3종 신고자료 ZIP 일괄 다운로드

## 개인정보 보호

이 앱은 정적 클라이언트 웹앱으로 동작합니다.

- 소득자료·강사명단·주민등록번호를 외부 서버로 전송하지 않음
- 주민등록번호를 localStorage / 쿠키에 저장하지 않음
- 화면에서는 주민등록번호를 마스킹하여 표시
- 암호화 Excel의 비밀번호는 파일을 읽는 동안 브라우저 메모리에서만 사용
- 원본 Excel의 암호를 제거하거나 변경하지 않음
- 암호가 풀린 Excel 파일을 별도로 저장하지 않음
- 외부 API 및 외부 CDN을 사용하지 않음
- 새로고침 또는 개인정보 메모리 비우기로 작업 데이터를 제거 가능

## 월별 사용 흐름

1. 기관 기본정보 준비
2. 소득자료 Excel 불러오기
3. 강사명단 연결
4. 준비 완료 확인
5. 귀속연월 및 신고 설정 확인
6. 3종 신고자료 생성 및 검토

> 실제 신고 전에는 생성된 신고자료의 내용과 해당 시점의 신고기준을 반드시 확인하세요.
