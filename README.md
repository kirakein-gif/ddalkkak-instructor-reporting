# 딸깍 방과후강사 신고자료

**Ddalkkak Instructor Reporting**  
방과후강사 관련 월별 신고자료를 한 번에 생성하는 브라우저 기반 업무자동화 도구입니다.

## 주요 기능

- 소득자료 Excel 여러 파일 불러오기
- 별도 강사명단과 성명 + 주민번호 앞 6자리 대조
- 원천세 전자신고파일 생성
- 간이지급명세서 TXT 또는 XLSX 생성
- 노무제공자 월보수액 신고 XLSX 생성
- 3종 신고자료 ZIP 일괄 다운로드
- 강사명단을 암호화된 `.ddkstaff` 파일로 저장 가능

## 개인정보 보호

이 앱은 **정적 클라이언트 웹앱**입니다. 사용자가 선택한 소득자료와 강사명단은 서버로 업로드하지 않고 현재 브라우저 메모리에서만 처리합니다.

- 주민등록번호 서버 전송 없음
- 주민등록번호 localStorage / 쿠키 저장 없음
- 화면에는 주민등록번호 전체를 표시하지 않음
- 새로고침 또는 개인정보 메모리 비우기 시 불러온 개인정보 제거
- 외부 CDN 없이 필요한 처리 코드를 앱 내부에 포함

> 실제 신고 전에는 생성된 신고파일의 내용과 최신 신고기준을 반드시 확인하세요.

## 실행

저장소의 `index.html`을 브라우저에서 열거나 GitHub Pages로 배포해 사용할 수 있습니다.
